- 通过 `withClearedProxyEnv` 包装异步 I/O 操作，在请求期间临时删除 `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` 等环境变量并在 finally 中恢复，确保直连目标服务器。
- 对 Node.js 内置模块使用 `require()` 延迟加载并配合 `@ts-ignore`，避免 esbuild 尝试将 `https`/`http`/`zlib`/`url` 打包进浏览器环境。
- multipart/form-data 请求体统一通过 `buildMultipartBody` 从内存 Buffer 拼接，字段以 `{ name, value }` 形式声明，字符串字段与文件字段走同一分支处理。
- 大对象上传采用分块写入（64KB）+ `drain` 事件背压控制，并以 5% 步长节流更新 Obsidian `Notice` 进度消息。
- 对外错误统一通过 Promise reject 抛出语义化 Error（如 'No API key configured'、'API returned empty response'、'ASR 上传超时 (30min)'），而非抛出未捕获异常。
