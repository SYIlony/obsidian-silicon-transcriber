- UI 组件通过继承 Obsidian 基类（`Modal`、`FuzzySuggestModal`、`PluginSettingTab`）实现，并在 `onOpen`/`display` 中清空容器后重新渲染 DOM。
- 设置项统一通过 `new Setting(containerEl).setName(...).setDesc(...).addText(...)` 链式构建，并在 `onChange` 回调中写入 `plugin.settings` 并调用 `saveSettings()` 持久化。
- 密码类设置使用统一的 `addPasswordSetting` 辅助方法，默认以 `type="password"` 输入框展示，并通过 `maskApiKey` 掩码占位符 + 聚焦时回填值的方式避免泄露已有密钥。
- 批量操作中的 DOM 更新采用局部刷新策略：通过 `dataset.path`、DOM 兄弟节点遍历和 CSS class（如 `is-selected`）增量更新 checkbox 与计数，而非整树重渲染以避免滚动位置丢失。
- 文件/文件夹树以自实现的 `TreeNode`（含 `children: Map<string, TreeNode>`、`allFiles`、`isFolder`）表示，并通过 `buildTree` → `pruneEmptyFolders` → `renderNode` 三段式递归构建与渲染。
- 对 Obsidian 未索引的文件（如符号链接目标）采用代理对象模式：用 `Object.create(TFile.prototype)` 构造最小可用的 `TFile`/`TFolder` 代理，仅填充 `path`、`name`、`stat`、`vault`、`parent` 等必要字段。
