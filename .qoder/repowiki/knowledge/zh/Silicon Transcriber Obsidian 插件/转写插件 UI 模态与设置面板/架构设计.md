本模块由三个独立的 Obsidian UI 组件构成，均基于 Obsidian API 构建：
- `batch-modal.ts` 导出 `BatchTranscribeModal`，继承 `Modal`，通过 `fs`/`path` 直接遍历 Vault 根目录收集音视频文件（支持符号链接/Junction），构建自定义 `TreeNode` 树结构并渲染为可折叠、可搜索、支持全选联动的文件树；已转写判断依赖 `utils.calculateNotePaths` 计算对应笔记路径并以文件大小阈值（>1000 字节）区分初始占位笔记与真实转写内容。
- `search-modal.ts` 导出 `TranscriptionSearchModal`，继承 `FuzzySuggestModal<SegmentLine>`，从当前 Markdown 视图扫描以 `> **` 开头的转写原文行，选中后自动展开折叠的 Callout（将 `> [!quote]-` 替换为 `> [!quote]`），并通过全局 `expandedCallouts` 数组记录以便 `restoreCalloutFolds` 在保存时恢复折叠状态。
- `settings-tab.ts` 导出 `SiliconTranscriberSettingTab`，继承 `PluginSettingTab`，通过 `PluginWithSettings` 接口反向持有插件实例，按 ASR / LLM / 报告 / 全局分析 / 思维导图 / 处理参数 / 数据迁移七个分组渲染设置项，所有变更通过 `plugin.saveSettings()` 持久化。
三者之间无相互依赖，仅共同依赖 `./settings`、`./types`、`./utils` 等底层模块，依赖方向单向指向这些共享工具。
